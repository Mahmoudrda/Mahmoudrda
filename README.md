## Selected work

| Engagement | Problem | Outcome |
|:--|:--|:--|
| **GCC health insurer**<br><sub>iOS and Android</sub> | No mobile attribution in place | Led a 4-person Adjust rollout: 7 media suppliers linked and a SKAN 4.0 conversion schema covering 25 events |
| **UAE theme park group**<br><sub>cross-domain booking</sub> | Purchases not credited to the campaigns that drove them | Analyzed 319 purchases, ruled out 6 suspected causes and isolated the two real ones: campaigns dropped mid-session and tagged internal links restarting sessions |
| **Multi-market retailer**<br><sub>4 Shopify stores, 7 GA4 properties</sub> | GA4 showed 28% more sessions than Shopify in the UAE | The first fix removed about a third of the excess, while KSA and Kuwait stayed within 4% of Shopify |
| **Large public sector site**<br><sub>server-side GTM</sub> | GA4 collection silently dead | Traced 100% data loss over about 16 days to an expired TLS certificate and delivered a monitoring runbook |
| **Enterprise advertisers**<br><sub>server-side tagging</sub> | Ad blockers and browser limits hiding conversions | Server-side GTM with 50+ Conversion API integrations, bringing the gap between GA4, ad platforms and backend down to 2–5% |
| **Tracking audits**<br><sub>GA4, GTM, pixels, consent</sub> | A full audit took about a week | Built an audit workflow with 248 automated checks that ends in a ranked fix plan, designed to take an afternoon |
